**日期**: 2026-04-07  
**源模型**: xps.001/Armature.001 (109 bones, XNA Lara Inase格式)

**目标PMX**: Collection 2/Purifier Inase 18 None_arm (263 bones)  
**预设**: xna_lara_Inase.json

## 差异分析

### 1. 命名规范差异 (重要)

| 类别 | 转换结果 | 目标PMX | 说明 |
|------|---------|---------|------|
| 左右对称骨骼 | `左肩`、`右肩` | `肩.L`、`肩.R` | 插件使用前缀(左/右)，目标使用后缀(.L/.R) |
| 手指骨骼 | `左親指０`、`右中指１` | `親指０.L`、`中指１.R` | 同上 |
| IK骨骼 | `左足ＩＫ`、`右つま先ＩＫ` | `足ＩＫ.L`、`つま先ＩＫ.R` | 同上 |
| 足D骨 | `足D.L` | `足D.L` | 一致 (.L/.R后缀) |
| 腰キャンセル | `腰キャンセル.L` | `腰キャンセル.L` | 一致 |

**影响**: 命名不统一。D骨和腰キャンセル用 `.L/.R` 后缀，而其他对称骨骼用 `左/右` 前缀。目标PMX全部使用 `.L/.R` 后缀。mmd_tools转换步骤可能会统一，但如果不经过mmd_tools，这个差异会影响PMX兼容性。

### 2. 缺失的结构骨骼 (重要)

以下骨骼存在于目标PMX但转换结果中缺失：

#### 2.1 肩链 (肩P / 肩C)
- **目标**: `上半身3 → 肩P.L → 肩.L → 肩C.L → 腕.L`
- **转换**: `上半身2 → 左肩 → 左腕`
- **缺失**: `肩P.L/R` (肩Parent)、`肩C.L/R` (肩Cancel)
- **影响**: 肩P和肩C是MMD中实现肩膀自然运动的重要辅助骨骼。缺失会导致肩膀动作僵硬。

#### 2.2 首1 (颈部中间骨)
- **目标**: `上半身3 → 首 → 首1 → 頭`
- **转换**: `上半身3 → 首 → 頭`
- **缺失**: `首1`
- **影响**: 原始XPS有两个neck骨骼(head neck lower/upper)，但转换时`head neck lower`映射为`首`、`head neck upper`映射为`頭`，丢失了中间层级。

#### 2.3 操作中心
- **目标**: 存在 `操作中心` 骨骼 (parent=None)
- **转换**: 缺失
- **影响**: 操作中心是MMD中用于全局操作的根骨骼。

#### 2.4 両目 (两眼联动)
- **目标**: 存在 `両目` (parent=頭)
- **转换**: 只有 `左目`、`右目`
- **影响**: 両目骨骼控制双眼联动，缺失会影响眼球运动。

#### 2.5 足先EX / つま先
- **目标**: 存在 `つま先.L/R` 和 `足先EX.L/R`
- **转换**: 有 `leg left toes`（未重命名），无 `足先EX`
- **影响**: 脚趾相关骨骼不完整。`leg left toes` 应映射为 `つま先`，`足先EX` 应作为D骨系的脚趾延伸创建。

#### 2.6 手指0骨 (指根)
- **目标**: 有 `人指０.L`、`中指０.L`、`薬指０.L`、`小指０.L` 等指根骨
- **转换**: 手指只有1-3节（如 `左人指１`、`左人指２`、`左人指３`），缺少第0节
- **影响**: 指根骨影响手指弯曲的自然度。

#### 2.7 ダミー (Dummy手首)
- **目标**: 存在 `ダミー.L/R` (parent=手首)
- **转换**: 缺失
- **影响**: 手首的辅助骨骼。

#### 2.8 乳奶
- **目标**: 存在 `乳奶.L/R` (parent=上半身2)
- **转换**: 有 `boob left 1/2`、`boob right 1/2`（未重命名）
- **影响**: 应将 boob 骨骼映射/重命名为乳奶。

### 3. 扭转骨链差异 (重要)

#### 目标PMX的扭转骨链 (串联式)：
```
腕.L → 腕捩.L → ひじ.L → 手捩.L → 手首.L
```
扭转骨**插入**在主骨骼链中间，形成串联。

#### 转换结果的扭转骨链 (并联式)：
```
左腕 → 左ひじ → 左手首    (主链)
左腕 → 左腕捩              (分支)
左ひじ → 左手捩             (分支)
```
扭转骨作为**分支**挂在主骨骼旁边，不在主链中。

**影响**: 这是最关键的结构差异之一。目标PMX中扭转骨是主链的一部分，变形时会正确传导旋转。当前并联结构需要依靠约束来模拟效果，可能不如串联准确。

此外目标还有 `腕捩1-3` 和 `手捩1-3` 等细分扭转骨及其shadow/dummy系统，转换结果没有这些。

### 4. IK骨骼差异 (次要)

| 项目 | 转换结果 | 目标PMX |
|------|---------|---------|
| 足IK親.L parent | None | None |
| 足IK親.R parent | None | 全ての親 |
| IK约束 | 左ひざ←左足ＩＫ (chain=2) | ひざ.L←足ＩＫ.L (chain=2) |

**差异**: 目标中 `足IK親.R` 的parent是 `全ての親`，而转换结果两侧都是 None（似乎目标的.L也是None，可能是历史遗留）。IK约束逻辑本身是一致的。

### 5. 肩的parent差异

- **转换**: `左肩` parent = `上半身2`
- **目标**: `肩.L` parent = `肩P.L` parent = `上半身3`
- **差异**: 肩骨挂载点不同。目标通过肩P连接到上半身3，转换结果直接连接上半身2。

### 6. Unused骨骼残留

转换结果中仍保留了以下未处理的骨骼（10个 unused + 其他原始骨骼）：
- `unused bip001 pelvis`, `unused bip001 xtra08/opp` 等
- `head jaw`, `head tongue 1-3`, `head lip *`, `head eyebrow *` 等面部骨骼
- `boob left/right 1/2`
- `leg left/right toes`
- `hair c/l/r`

目标PMX中这些骨骼有不同的处理方式（部分重命名为日文，部分保留英文名）。

## 优先级排序

### P0 (影响基本功能)
1. **命名规范统一**: 所有左右对称骨骼应使用 `.L/.R` 后缀格式（或提供选项）
2. **扭转骨链结构**: 应改为串联式（腕→腕捩→ひじ→手捩→手首）

### P1 (影响完整度)
3. **肩P/肩C 骨骼**: 补全肩链
4. **操作中心**: 补全根骨骼
5. **首1**: 利用原始双neck骨骼补全
6. **足先EX / つま先**: 补全脚趾骨骼链
7. **手指0骨**: 补全指根骨骼

### P2 (影响细节)
8. **両目**: 补全双眼联动骨骼
9. **ダミー**: 补全手首辅助骨骼
10. **乳奶重命名**: boob → 乳奶
11. **腕捩1-3 / 手捩1-3**: 细分扭转骨
12. **IK親 parent**: 统一足IK親的parent设置
