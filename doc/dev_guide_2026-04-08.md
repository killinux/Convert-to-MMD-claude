## 一、MMD 核心概念

### 1.1 骨骼命名规范

MMD/PMX 有两套命名系统：

| 场景 | 格式 | 示例 | 说明 |
|------|------|------|------|
| PMX 文件内部 | 左/右前缀 | 左腕、右足ＩＫ | VMD 动作文件用此名称匹配骨骼 |
| Blender 内部 | .L/.R 后缀 | 腕.L、足ＩＫ.R | Blender 原生支持镜像操作 |

**关键**: VMD 匹配用的是 PMX 的 `name_j`（日文名）字段，不是 Blender 骨骼名。所以 Blender 内部可以用 `.L/.R`，但导出 PMX 前必须把 `name_j` 设为 `左/右` 格式。

特殊情况：`腰キャンセル` 用后缀（`腰キャンセル左`/`腰キャンセル右`），不是前缀。

### 1.2 センター骨骼方向与 VMD 旋转

センター（Center）是 MMD 的**重心骨骼**，控制角色整体的上下移动和前后倾斜。VMD 动作中下蹲、跳跃、身体前倾等都通过旋转/移动センター实现。

```
全ての親 → センター → グルーブ → 腰 → 上半身 / 下半身
```

**骨骼方向决定本地坐标系**：Blender 骨骼的本地 Y 轴由 head→tail 方向决定。VMD 存储的旋转值是相对于骨骼本地坐标系的。

- **PMX 标准**：センター的 **tail 在 head 下方**（朝下），本地 Y 轴朝下
- **错误方向**：tail 在 head 上方（朝上），本地 Y 轴朝上

如果方向反了（差180°），VMD 说"绕 X 轴旋转30°（前倾）"实际变成后倾，所有挂在センター下面的骨骼（腿、腰、下半身）全部反向，看起来腿拧到后面。

**修复位置**：步骤2 `complete_missing_bones` 中 `bone_properties` 的センター定义，确保 head.z > tail.z。

### 1.3 D 骨机制（分离控制与变形）

MMD 的 D 骨是一种"控制与变形分离"的设计：

```
VMD 动作 → 主骨（足.L）→ IK 驱动
                ↓ 付与親（additional transform, rotation ×1.0）
            D骨（足D.L）→ 实际变形 mesh
```

- **主骨**（足.L、ひざ.L、足首.L）：接收 IK/动作控制，**不带权重**
- **D 骨**（足D.L、ひざD.L、足首D.L）：**带权重**，通过付与親跟随主骨旋转

### 1.3 付与親（Additional Transform）

PMX 的骨骼属性，意思是"我的变换 = 目标骨骼的变换 × 影响度"：

| 骨骼 | 付与親目标 | 影响度 | 含义 |
|------|-----------|--------|------|
| 足D.L | 足.L | +1.0 | 完全复制足的旋转 |
| ひざD.L | ひざ.L | +1.0 | 完全复制ひざ的旋转 |
| 足首D.L | 足首.L | +1.0 | 完全复制足首的旋转 |
| 腰キャンセル.L | 下半身 | -1.0 | **反转**下半身的旋转（抵消） |

在 Blender 中，付与親用 `mmd_bone.additional_transform_bone` + `mmd_bone.has_additional_rotation` 表示。在 Blender 内部工作时，等价机制是 shadow/dummy + TRANSFORM 约束（步骤6创建），但这些约束在 PMX 导出/导入后会丢失，因此必须同时设置付与親属性。

### 1.4 Shadow/Dummy 三层约束机制

这是 Blender 内部实现付与親的方式（步骤6创建）：

```
_dummy_足D.L (parent=足.L)     ← 挂在主骨下，跟随主骨运动
       ↓ COPY_TRANSFORMS
_shadow_足D.L (parent=腰キャンセル.L)  ← 中间层
       ↓ TRANSFORM (rotation 1:1)
足D.L (parent=腰キャンセル.L)    ← D骨获得主骨的旋转
```

### 1.5 肩链（肩P / 肩C）

MMD 标准的肩链提供额外的控制层级：

```
上半身3 → 肩P.L → 肩.L → 肩C.L → 腕.L → 腕捩.L → ひじ.L → 手捩.L → 手首.L
```

- **肩P**（肩 Parent）：肩的父骨骼，提供独立旋转控制
- **肩C**（肩 Cancel）：抵消肩膀旋转对手臂的影响

### 1.6 扭转骨链（串联式）

MMD 的扭转骨插入在主链中间，形成串联：

```
腕.L → 腕捩.L → ひじ.L → 手捩.L → 手首.L
```

而不是并联分支（旧版实现）：
```
腕.L → ひじ.L → 手首.L   （主链）
腕.L → 腕捩.L              （分支）× 错误
```

## 二、今日修改内容

### P0-1: 命名统一为 .L/.R 后缀

**改动文件**: `bone_map_and_group.py`, `bone_utils.py`, `bone_operator.py`, `ik_operator.py`, `leg_operator.py`

**原理**: 将所有对称骨骼从 `左/右` 前缀改为 `.L/.R` 后缀。Blender 原生支持 `.L/.R` 格式的镜像操作、对称姿态粘贴等功能。所有步骤内部统一用 `.L/.R`，仅在导出 PMX 时通过步骤8转换 name_j 为 `左/右`。

**影响范围**:
- `bone_map_and_group.py`: mmd_bone_map 值、mmd_bone_group 列表
- `bone_utils.py`: DEFAULT_ROLL_VALUES
- `bone_operator.py`: complete_missing_bones 中的硬编码名称
- `ik_operator.py`: IK 骨骼名、约束引用、SHADOW_DUMMY_DEFS
- `leg_operator.py`: LOWER_BODY_TARGETS、PHASE2_TARGETS、SPLIT_BONE_TARGETS

### P0-2: 扭转骨改为串联式

**改动文件**: `leg_operator.py` (`complete_twist_bones`)

**原理**: 创建扭转骨后，将 ひじ re-parent 到 腕捩，将 手首 re-parent 到 手捩。

### P1-1: 操作中心

**改动文件**: `bone_operator.py`

在 bone_properties 中添加操作中心骨骼（parent=None, use_deform=False）。

### P1-2: 首1（颈部中间骨）

**改动文件**: `bone_operator.py`

**难点**: XPS 中 首.tail == 頭.head（同一个点），导致 首1 是零长度骨骼，Blender 在 mode switch 时会丢弃。

**解决**: 将 首1 放在首.head 和 頭.head 的中间点，确保非零长度。同时将 首.tail 缩短到该中间点。

### P1-3: 肩P / 肩C

**改动文件**: `bone_operator.py`

在 limb_defs 中添加肩P.L/R（parent=上半身3）和 肩C.L/R（parent=肩.L/R），更新 肩 的 parent 为 肩P，腕 的 parent 为 肩C。

### P1-4: つま先 / 足先EX

**改动文件**: `bone_map_and_group.py`, `presets/xna_lara_Inase.json`, `bone_operator.py`, `leg_operator.py`

- mmd_bone_map 的 toe 映射从 `足先EX` 改为 `つま先`
- 预设添加 "leg left/right toes" 映射
- 步骤2 设置 つま先 parent=足首
- 步骤3 D骨创建中添加 足先EX（parent=足首D）

### P1-5: 手指0骨

**改动文件**: `bone_operator.py`

在 limb_defs 中创建 人指０/中指０/薬指０/小指０ .L/R，位置在 手首 和 指１ 的中间点，re-parent 指１→指０。

### PMX 属性设置（步骤8）

**改动文件**: `preset_operator.py`, `__init__.py`, `ui_panel.py`

新增独立 operator `OBJECT_OT_setup_pmx_attributes`，面板按钮"8. 设置PMX属性"：

1. **name_j**: 遍历所有骨骼，`.L` → `左` 前缀，`.R` → `右` 前缀
2. **付与親**: 设置 D 骨的 `additional_transform_bone` 和 `has_additional_rotation`
3. `_dummy_`/`_shadow_` 骨骼的 name_j 设为空

"使用mmdtools转换格式"按钮会自动调用步骤8。

### 骨骼名互转按钮

**改动文件**: `bone_operator.py`, `__init__.py`, `ui_panel.py`

面板上两个按钮：
- `.L/.R → 左/右`: 将 Blender 骨骼名转为日文格式
- `左/右 → .L/.R`: 将日文格式转回 Blender 格式

### mmd_tools 外部修复

**文件**: Mac 上 `mmd_tools/auto_scene_setup.py`

`frame_start`/`frame_end` 赋值加 `int()`，修复 VMD 导入时的 TypeError。

## 三、转换流程（1-8 步）

```
1. 重命名为MMD          ← bone_map 映射，骨骼统一为 .L/.R 格式
2. 补全缺失骨骼          ← 操作中心、グルーブ、腰、上半身3、首1、肩P/C、指０、下半身、腰キャンセル
2.1 补全扭转骨          ← 腕捩/手捩，串联式 re-parent
3. 补全D骨             ← 足D/ひざD/足首D + 足先EX
4. 补全腰キャンセル       ← 通常在步骤2已创建
5. 分配权重             ← unused→主骨→D骨，下半身清理
6. 添加MMD IK          ← IK骨骼 + shadow/dummy 约束
7. 创建骨骼集合          ← bone groups
8. 设置PMX属性          ← name_j + 付与親（导出前必须执行）
```

步骤8之后可以用"使用mmdtools转换格式"或 mmd_tools 自带功能导出。

## 四、XPS→MMD 通用注意事项

### 4.1 预设文件

每种 XPS 骨骼格式需要一个预设 JSON（`presets/` 目录下），映射 XPS 骨骼名到插件属性名。关键字段：

```json
{
    "all_parents_bone": "XPS根骨骼名",
    "center_bone": "XPS中心骨骼名",
    "upper_body_bone": "XPS上半身骨骼名",
    "left_shoulder_bone": "XPS左肩骨骼名",
    "left_toe_bone": "XPS左脚趾骨骼名",
    ...
}
```

**注意**: 空字符串表示该骨骼在 XPS 中不存在，步骤2会自动创建。

### 4.2 unused 骨骼处理

XPS 模型通常有大量辅助骨骼（如 `bip001 pelvis`、`muscle_elbow` 等），这些骨骼名以 `unused` 开头（步骤1未映射的骨骼保留原名）。步骤5会将它们的权重按空间距离分配到最近的 MMD 骨骼。

如果某个 unused 骨骼的权重分配不正确，可以：
1. 在 `FORCED_TARGETS` 中添加强制映射
2. 在 `SPLIT_BONES` / `SPLIT_BONE_TARGETS` 中添加需要逐顶点拆分的骨骼

### 4.3 零长度骨骼问题

XPS 中经常出现 parent.tail == child.head 的情况。如果需要在两个骨骼之间插入新骨骼（如 首1），必须确保新骨骼有非零长度，否则 Blender 在 mode switch 时会丢弃。

**解决方案**: 使用两个骨骼 head 的中间点作为新骨骼的 head，原 child.head 作为 tail。

### 4.4 新 XPS 格式适配清单

适配一种新的 XPS 骨骼格式时：

1. **创建预设**: 导入 XPS 模型，在面板中手动映射每个骨骼，导出为预设 JSON
2. **检查 unused 骨骼**: 跑完步骤5后检查哪些 unused 骨骼没有被处理，可能需要添加到 FORCED_TARGETS 或调整 PHASE2_TARGETS
3. **检查权重**: 用 Weight Paint 模式检查关键骨骼（下半身、足、ひざ 等）的权重分布是否合理
4. **验证 D 骨跟随**: 在 Pose 模式旋转主骨，检查 D 骨是否跟随（步骤6的约束是否正确）
5. **PMX 导出测试**: 导出 PMX → 导入 → 加载 VMD 动作，检查上半身和下半身是否都能正确驱动

### 4.5 常见问题排查

| 症状 | 原因 | 解决 |
|------|------|------|
| VMD 动作完全不动 | name_j 不匹配 | 执行步骤8 |
| 上半身动但腿不动 | D骨没有付与親 | 执行步骤8 |
| 腿拧到后面/身体反向 | センター骨骼方向反了 | 步骤2中确保センター head.z > tail.z |
| 肩膀动作僵硬 | 缺少肩P/肩C | 检查步骤2是否创建了肩链 |
| 手指不弯曲 | 缺少指０骨 | 检查步骤2是否创建了指根骨 |
| 扭转不自然 | 扭转骨是并联式 | 检查步骤2.1是否 re-parent |
| 导入 VMD 报 TypeError | mmd_tools frame_start bug | 修复 auto_scene_setup.py |
